# cka-training
This repository is a compendium of training material for the CKA exam


# Prerequisites
This repo has been tested using the following versions of tools 
(you need to have them installed in your host computer):
```shell
virtualbox@7.2.22
vagrant@2.4.9
ubuntu/noble@24.04
```


# How to use this repository
The repository is structured replicating the index of questions for the CKA exam, extracted from the different additioanl resources

## Infra
### Local
contains the resources for generating a local cluster. It uses VirtualBox full machines and vagrant (to simulate better the exam)
### CICD
contains the resources for generating a CICD-compatible cluster (using Kind). Useful to automate validations in pipelines, not for replicating exam scenarios


# Additional Open Source resources
1. [How to practice fro CKA for Free in 2026](https://sailor.sh/blog/how-to-practice-cka-for-free/) - Contains a set of tips for the exa, as well as a link to a free exam simulator to run locally
2. [killercoda CKA Scenarios](https://killercoda.com/) - A web based resource containing exercises for specific CKA topics
3. [Exam training repo](https://github.com/theplatformlab/CKA-Certified-Kubernetes-Administrator) - Repo containing training, includes 2 mock exams
4. [CKA Tutorial](https://github.com/larkintuckerllc/k8s-cka-tutorial) - Repo containing videos with step by step CKA explanations. Based in AWS
5. [Official Kubernetes docs](https://kubernetes.io/docs/home/) - Official docs
6. [KodeKloud CKA training course](https://kodekloud.com/courses/cka-certification-course-certified-kubernetes-administrator/) - The best course, but paid. Useful to see the index and create exercises
7. [KodeKloud CKA certification index](https://github.com/kodekloudhub/certified-kubernetes-administrator-course) - Repo associated to previous entry. Useful to generate exercises and a study guide
8. [CKA exercises](https://github.com/xooooooooox/cka-exercises) - Compendium of lots of exercises to practise
9. [Index of topics](https://www.golinuxcloud.com/kubernetes-tutorial/#faq-do-i-need-docker-to-learn-kubernetes) - Free Course to learn kubernetes
10. [CKA certification guide](https://github.com/techiescamp/cka-certification-guide) - Repo with a guide for taking the certification
